### III. Data Manipulation and Feature Engineering

**Industry Alignment:** Data manipulation is crucial for extracting meaningful insights from health and lifestyle data. Creating derived features often reveals patterns that raw sleep metrics don't show, and filtering helps focus analysis on relevant demographic or lifestyle segments.

For numerical categories, I decided to split them into categorical levels to make it easier to comprehend.

**Key Components:**

1. **Creating New Variables**
   ```python
   # Sleep quality categories
   df['sleep_quality_category'] = pd.cut(df['Sleep_Quality'], 
                                        bins=[0, 3, 5, 7, 10], 
                                        labels=['Poor', 'Fair', 'Good', 'Excellent'])
   
   # Sleep duration categories
   df['sleep_duration_category'] = pd.cut(df['Sleep_Duration'], 
                                         bins=[0, 6, 7, 8, 12], 
                                         labels=['Short', 'Below Average', 'Optimal', 'Long'])
   
   # Age groups
   df['age_group'] = pd.cut(df['Age'], 
                           bins=[0, 25, 35, 50, 100], 
                           labels=['Young Adult', 'Adult', 'Middle-aged', 'Senior'])
   
   # Stress level categories
   df['stress_level'] = pd.cut(df['Stress_Level'], 
                              bins=[0, 3, 6, 8, 10], 
                              labels=['Low', 'Moderate', 'High', 'Very High'])
   
   # Physical activity intensity
   df['activity_intensity'] = pd.cut(df['Physical_Activity_Level'], 
                                    bins=[0, 30, 60, 120, 300], 
                                    labels=['Sedentary', 'Light', 'Moderate', 'Active'])
   
   # Sleep efficiency (quality per hour of sleep)
   df['sleep_efficiency'] = df['Sleep_Quality'] / df['Sleep_Duration']
   
   # Lifestyle score (composite of activity and stress)
   df['lifestyle_score'] = (df['Physical_Activity_Level'] / 10) - (df['Stress_Level'] / 10)
   ```

2. **Data Filtering and Subsetting**
   ```python
   # Good sleepers only
   good_sleepers = df[df['sleep_quality_category'].isin(['Good', 'Excellent'])]
   
   # High stress individuals
   high_stress = df[df['stress_level'].isin(['High', 'Very High'])]
   
   # Active lifestyle individuals
   active_lifestyle = df[df['activity_intensity'].isin(['Moderate', 'Active'])]
   
   # Age-specific analysis
   young_adults = df[df['age_group'] == 'Young Adult']
   seniors = df[df['age_group'] == 'Senior']
   
   # Occupation-based filtering
   office_workers = df[df['Occupation'] == 'Office Worker']
   healthcare_workers = df[df['Occupation'] == 'Healthcare Worker']
   ```

3. **Aggregation and Summary Statistics**
   ```python
   # Sleep patterns by age group
   age_sleep_analysis = df.groupby('age_group').agg({
       'Sleep_Duration': ['mean', 'std'],
       'Sleep_Quality': ['mean', 'std'],
       'sleep_efficiency': 'mean',
       'Stress_Level': 'mean'
   }).round(2)
   
   # Occupation impact on sleep
   occupation_sleep = df.groupby('Occupation').agg({
       'Sleep_Duration': 'mean',
       'Sleep_Quality': 'mean',
       'Stress_Level': 'mean',
       'Physical_Activity_Level': 'mean'
   }).round(2)
   
   # Stress and activity relationship
   stress_activity_analysis = df.groupby('stress_level').agg({
       'Physical_Activity_Level': ['mean', 'std'],
       'Sleep_Quality': 'mean',
       'Sleep_Duration': 'mean'
   })
   ```

4. **Data Reshaping for Analysis**
   ```python
   # Pivot table for demographic analysis
   demographic_sleep = df.pivot_table(
       values=['Sleep_Duration', 'Sleep_Quality', 'Stress_Level'],
       index='Gender',
       columns='age_group',
       aggfunc='mean'
   )
   
   # Lifestyle factors matrix
   lifestyle_matrix = df.pivot_table(
       values='Sleep_Quality',
       index='activity_intensity',
       columns='stress_level',
       aggfunc='mean',
       fill_value=0
   )
   ```

**Interpretation:** With a p-value < 0.05, we reject the null hypothesis that the data follows a normal distribution, indicating that non-parametric methods may be more appropriate for this analysis.

**Box-Cox Transformation Assessment:**
To determine if a transformation could improve the normality of the sleep duration data, we applied the Box-Cox transformation method:

- **Optimal lambda value:** 0.483
- **Original data normality:** Not normal (p < 0.001)
- **Transformed data normality:** Still not normal (p < 0.001)
- **Improvement:** No meaningful improvement in normality

**Conclusion:** The Box-Cox transformation does not meaningfully improve the normality of the sleep duration data. Therefore, we proceed with the original data and use non-parametric statistical methods throughout the analysis.

## Statistical Method Selection

### Response Variable Analysis
Before selecting appropriate statistical methods, we must understand the nature of our response variables:

**Sleep Quality Variable:**
- **Original Scale:** 1-10 continuous scale
- **Categorical Transformation:** Converted to ordinal categories (Poor: 1-3, Fair: 4-5, Good: 6-7, Excellent: 8-10)
- **Statistical Method Decision:** Ordinal logistic regression is appropriate for ordinal categorical outcomes

**Sleep Duration Variable:**
- **Scale:** Continuous (hours)
- **Distribution:** Non-normal (Shapiro-Wilk p < 0.001)
- **Statistical Method Decision:** Non-parametric methods preferred

**Rationale for Method Selection:**
1. **Ordinal Logistic Regression for Sleep Quality:** Appropriate for ordinal categorical response variables where categories have meaningful order
2. **Non-parametric Tests for Sleep Duration:** Required due to non-normal distribution
3. **Proportional Odds Assumption:** Ordinal logistic regression assumes that the effect of predictors is consistent across all category thresholds

## Model Selection Process

To determine the optimal regression model for predicting sleep quality, we systematically evaluated various predictor combinations using both statistical criteria and model diagnostics. The selection process involved the following steps on an ordinal regression model (sleep quality, the response variable, is an ordinal categorical variable (Poor, Fair, Good, Excellent)):

### 1. Initial Screening of Predictors

All potential variables were initially considered:

**Demographics:** Age, Gender, Occupation

**Lifestyle:** Physical Activity Level, Stress Level, Daily Steps, Heart Rate

**Health:** BMI Category

We first used correlation analysis and domain understanding to filter variables that lacked theoretical or statistical relevance.

### 2. Multicollinearity Check

Using statsmodels' variance_inflation_factor, we computed VIF scores for each predictor in the initial model. Variables with VIF > 5 were flagged for potential multicollinearity. To resolve this:

- Highly collinear variables were removed
- In some cases, domain relevance overruled VIF thresholds if interpretability was prioritized

### 3. Stepwise Regression with AIC

We implemented stepwise regression (both forward and backward) using statsmodels and a custom loop that minimizes Akaike Information Criterion (AIC).

**Procedure:**
- Start with an intercept-only model
- Iteratively add or remove predictors based on which change yields the largest AIC reduction
- Continue until no further improvement is possible

This method balances model complexity and fit and helps avoid overfitting.

### 4. Cross-Validation for Generalizability

To validate predictive performance, we used 5-fold cross-validation with scikit-learn's cross_val_score on a linear regression model (LinearRegression()):

- Evaluated using negative mean squared error (neg-MSE) and R²
- Averaged scores across folds for fair comparison between models

This ensured our final model generalized well beyond the training set.

### 5. Final Model Selection

The best model based on AIC and cross-validation performance included the following predictors:

- Age
- Physical Activity Level
- Stress Level
- Heart Rate
- Daily Steps

These variables consistently showed strong predictive power, low multicollinearity, and satisfied key model assumptions.

### 6. Final Diagnostics

After selecting the model, we validated its assumptions:

- **Linearity:** Verified via residuals vs fitted plots
- **Normality of Residuals:** Checked using Q-Q plots and the Shapiro-Wilk test
- **Homoscedasticity:** Assessed via Breusch-Pagan test and residual spread
- **Independence:** No time-based autocorrelation present
- **Multicollinearity:** Final VIF values all < 5

An ordinal logistic regression model was developed to predict sleep quality categories based on multiple factors. To reiterate, this approach is appropriate since sleep quality is an ordinal categorical variable (Poor, Fair, Good, Excellent).

The model diagnostics include comprehensive assessment of the ordinal logistic regression model:

#### 5. Model Coefficients and Odds Ratios

**Ordinal Logistic Regression Results:**
The model estimates the probability of being in higher sleep quality categories based on predictor variables.

**Coefficient Estimates (Log-Odds):**
- **Age:** 0.096 (p < 0.001) - Significant
- **Physical Activity Level:** 0.031 (p = 0.047) - Significant
- **Stress Level:** -3.520 (p < 0.001) - Highly significant
- **Heart Rate:** 0.171 (p = 0.048) - Significant
- **Daily Steps:** 0.0006 (p = 0.010) - Significant

**Odds Ratios (for moving to higher sleep quality category):**
- **Age:** 1.101 - Each year of age increases odds of better sleep quality by 10.1%
- **Physical Activity Level:** 1.032 - Each unit increase increases odds by 3.2%
- **Stress Level:** 0.030 - Each unit increase decreases odds by 97.0% (strong negative effect)
- **Heart Rate:** 1.186 - Each bpm increase increases odds by 18.6%
- **Daily Steps:** 1.001 - Each step increases odds by 0.1%

**Interpretation:** All predictors are statistically significant (p < 0.05). Stress level has the strongest effect, with higher stress dramatically reducing the odds of better sleep quality.
