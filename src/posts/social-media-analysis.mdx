### II. Data Cleaning and Preparation

The analysis began with comprehensive data quality assessment:

1. **Missing Value Analysis:** Identified and documented any missing data points
2. **Data Type Validation:** Ensured proper data types for categorical and numerical variables
3. **Outlier Detection:** Used IQR method to identify and handle outliers systematically
4. **Data Consistency Checks:** Verified logical ranges for all variables

**Dataset Overview:**
- **User_ID:** Unique identifier for each user
- **App:** The social media platform being used (Facebook, Instagram, Twitter, Snapchat, TikTok, LinkedIn, Pinterest)
- **Daily_Minutes_Spent:** Total time a user spends on the app each day (5-500 minutes)
- **Posts_Per_Day:** Number of posts a user creates per day (0-20)
- **Likes_Per_Day:** Total number of likes a user receives on their posts each day (0-200)
- **Follows_Per_Day:** The number of new followers a user gains daily (0-50)

### IV. Data Manipulation and Feature Engineering

**Industry Alignment:** Data manipulation is crucial for extracting meaningful insights from social media data. Creating derived features often reveals patterns that raw engagement metrics don't show, and filtering helps focus analysis on relevant user segments.

**Key Components:**

1. **Creating New Variables**
   ```python
   # Engagement rate calculation
   df['engagement_rate'] = (df['Likes_Per_Day'] + df['Follows_Per_Day']) / df['Posts_Per_Day'].replace(0, 1)
   
   # Usage intensity categories
   df['usage_intensity'] = pd.cut(df['Daily_Minutes_Spent'], 
                                 bins=[0, 30, 60, 120, 500], 
                                 labels=['Light', 'Moderate', 'Heavy', 'Very Heavy'])
   
   # Platform type classification
   df['platform_type'] = df['App'].map({
       'Facebook': 'Social Network',
       'Instagram': 'Visual Social',
       'Twitter': 'Microblogging',
       'Snapchat': 'Ephemeral',
       'TikTok': 'Short-form Video',
       'LinkedIn': 'Professional',
       'Pinterest': 'Visual Discovery'
   })
   
   # Productivity metrics
   df['likes_per_minute'] = df['Likes_Per_Day'] / df['Daily_Minutes_Spent']
   df['posts_per_hour'] = df['Posts_Per_Day'] * 60 / df['Daily_Minutes_Spent']
   ```

2. **Data Filtering and Subsetting**
   ```python
   # Active users only
   active_users = df[df['Posts_Per_Day'] > 0]
   
   # High engagement users
   high_engagement = df[df['engagement_rate'] > df['engagement_rate'].quantile(0.8)]
   
   # Platform-specific analysis
   visual_platforms = df[df['platform_type'].isin(['Visual Social', 'Visual Discovery'])]
   professional_platforms = df[df['platform_type'] == 'Professional']
   
   # Usage patterns by intensity
   heavy_users = df[df['usage_intensity'].isin(['Heavy', 'Very Heavy'])]
   ```

3. **Aggregation and Summary Statistics**
   ```python
   # Platform performance metrics
   platform_metrics = df.groupby('App').agg({
       'Daily_Minutes_Spent': ['mean', 'std', 'count'],
       'engagement_rate': 'mean',
       'Posts_Per_Day': 'mean',
       'Likes_Per_Day': 'mean'
   }).round(2)
   
   # Usage intensity analysis
   intensity_analysis = df.groupby('usage_intensity').agg({
       'engagement_rate': ['mean', 'std'],
       'Posts_Per_Day': 'mean',
       'Daily_Minutes_Spent': 'mean'
   })
   ```

4. **Data Reshaping for Analysis**
   ```python
   # Pivot table for platform comparison
   platform_comparison = df.pivot_table(
       values=['Daily_Minutes_Spent', 'engagement_rate', 'Posts_Per_Day'],
       index='App',
       aggfunc='mean'
   )
   
   # User behavior matrix
   user_behavior = df.pivot_table(
       values='Daily_Minutes_Spent',
       index='User_ID',

       fill_value=0
   )
   ```

**Quality Checks for Transformed Data:**
```python
# Validate social media transformations
def validate_social_media_transformations(df):
    """
    Quality checks for social media data transformations
    """
    checks = {}
    
    # Check for infinite engagement rates
    checks['infinite_engagement'] = np.isinf(df['engagement_rate']).sum()
    
    # Check for negative values
    checks['negative_metrics'] = (df[['likes_per_minute', 'posts_per_hour']] < 0).sum().sum()
    
    # Check for unreasonable engagement rates
    checks['unusual_engagement'] = (df['engagement_rate'] > df['engagement_rate'].quantile(0.99)).sum()
    
    # Check for missing platform classifications
    checks['missing_platform_type'] = df['platform_type'].isnull().sum()
    
    return checks

transformation_checks = validate_social_media_transformations(df)
print("=== Social Media Transformation Quality Checks ===")
for check, result in transformation_checks.items():
    print(f"{check}: {result}")
```
